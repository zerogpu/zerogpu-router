# Code of Conduct

## Our Pledge

We want this project to be a welcoming, professional space for people building agent tooling, MCP integrations, and model-routing infrastructure.

Participants are expected to be respectful, constructive, and considerate of differing experience levels and backgrounds.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect different viewpoints and implementation preferences.
- Focus criticism on code, behavior, and tradeoffs, not people.
- Give maintainers enough context to reproduce bugs or evaluate proposals.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private credentials, logs, or user data.
- Trolling, sustained disruption, or bad-faith participation.
- Sexualized language or imagery in project spaces.

## Enforcement

Maintainers may remove comments, close issues, restrict participation, or ban users from project spaces when behavior violates this code of conduct.

Report concerns privately to `hello@zerogpu.ai`.
